Projeto

Informação pública não deveria exigir uma caça ao tesouro.

O Suzano Aberta reduz a distância entre “a publicação existe” e “uma pessoa consegue encontrá-la, conferir a origem e reutilizar o dado”.

LocalizávelUm índice único pesquisa fontes que normalmente vivem em portais, páginas, PDFs e APIs diferentes.
RastreávelA origem permanece associada ao registro para que a pessoa possa voltar ao documento responsável.
ReutilizávelO mesmo núcleo alimenta portal, API, Python, CLI e snapshot SQLite.
ConservadorDado ausente não é completado por suposição e relação textual não vira acusação.

O problema

Informações públicas podem estar legalmente disponíveis e ainda assim ser difíceis de localizar. O material pode aparecer em páginas institucionais, PDFs, planilhas, portais diferentes, sistemas nacionais ou endereços que mudam ao longo do tempo.

O que o projeto faz

O sistema descobre fontes públicas, coleta registros, extrai conteúdo de documentos compatíveis, preserva proveniência e mudanças, cria um índice de busca e publica versões verificáveis do acervo. A experiência web é uma camada sobre essa infraestrutura — não um banco isolado feito só para a interface.

O que o projeto não faz

  • Não se apresenta como site oficial da Prefeitura ou da Câmara.
  • Não atribui automaticamente culpa, irregularidade, desempenho ou intenção a agentes públicos.
  • Não substitui documentos oficiais, pareceres técnicos ou análise jurídica.
  • Não contorna autenticação ou bloqueios para fingir que uma fonte é pública.
  • Não promete cobertura absoluta de toda informação existente.

Princípios

ClarezaLinguagem direta e interfaces previsíveis antes de efeitos visuais.
RastreabilidadeCada resultado deve manter o caminho até a origem.
AcessibilidadeTeclado, foco, contraste, zoom, semântica e movimento reduzido são requisitos de engenharia.
ResiliênciaColeta, snapshot, API e portal são desacoplados; uma falha não deve destruir o último acervo válido.
NeutralidadeO software organiza evidências públicas e evita inferências políticas automáticas.

Arquitetura

fontes públicas
      ↓
coleta + documentos + histórico
      ↓
normalização + SQLite + FTS5
      ↓
proveniência + relações determinísticas
      ↓
validação + checksum + snapshot
      ↓
portal ── API HTTP ── Data API ── Python ── CLI

Todo o código e a metodologia ficam disponíveis no repositório do projeto.

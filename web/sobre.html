Projeto

Informação pública precisa ser encontrável.

O Suzano Aberta reúne tecnologia de coleta, preservação, pesquisa e distribuição para reduzir a distância entre “o dado existe” e “qualquer pessoa consegue encontrá-lo”.

O problema

Informações públicas podem estar corretas e legalmente disponíveis, mas espalhadas entre páginas, PDFs, planilhas, portais diferentes e endereços que mudam com o tempo. A proposta do Suzano Aberta é criar uma camada de organização e pesquisa sem esconder a origem.

O que o projeto faz

O sistema descobre fontes, coleta registros públicos, extrai conteúdo de documentos compatíveis, registra proveniência e mudanças, cria um índice de busca e publica versões verificáveis do acervo. O mesmo núcleo pode ser consultado pela linha de comando, pela biblioteca Python, pela API e por este portal.

O que o projeto não faz

  • Não se apresenta como site oficial da Prefeitura ou da Câmara.
  • Não atribui automaticamente culpa, irregularidade ou nota a agentes públicos.
  • Não substitui documentos oficiais, pareceres técnicos ou análise jurídica.
  • Não tenta contornar controles de acesso de portais que bloqueiam automação.

Princípios

ClarezaLinguagem direta e interfaces previsíveis.
RastreabilidadeCada resultado preserva o vínculo com sua fonte.
AcessibilidadeSemântica, teclado, contraste, zoom e movimento reduzido são requisitos de projeto.
ResiliênciaPortal, API e coleta são desacoplados; uma falha não deve destruir o acervo publicado.
NeutralidadeO software organiza evidências públicas e evita inferências políticas automáticas.

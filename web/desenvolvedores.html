API read-only, pacote Python, CLI e snapshot SQLite completo. Para grandes volumes, baixe o snapshot; para consultas de aplicação, use a API.

API v1

A API é deliberadamente somente leitura. Ela não expõe rotas públicas de coleta, atualização ou reindexação.

GET https://api.exemplo.suzanoaberta/v1/stats

Contrato e rastreabilidade

Os modelos preservam identificador, tipo, título, atributos, fonte e instante de coleta. Consulte o repositório para o esquema completo, exemplos e política de compatibilidade.

Código sob Apache-2.0. Dados e documentos permanecem sujeitos às condições de suas fontes originais.

Duas camadas públicas: uma Data API estática e resiliente para catálogo e download em massa; e uma API consultiva para filtros, paginação e aplicações interativas.

Data API pública

É gerada a partir do mesmo snapshot validado usado pelo portal e publicada junto do GitHub Pages. As coleções completas são ordenadas por data efetiva, do item mais recente para o mais antigo.

GET ./api/v1/documentos.json.gz

API consultiva v1.1

A camada FastAPI é somente leitura e oferece paginação, busca textual, intervalo de datas e ordenação. A data efetiva usa a data pública do registro; quando a fonte informa apenas o ano, esse fato permanece identificado.

GET API consultiva/v1/search?q=educacao&sort=date_desc
GET API consultiva/v1/records?date_from=2026-01-01&date_to=2026-12-31
GET API consultiva/v1/documents?date_from=2026-01-01&sort=date_desc
GET API consultiva/v1/legislation?kind=proposicao&sort=date_desc

Semântica de datas

record é a data publicada pela fonte; year indica que só o ano foi encontrado; observed é a data em que o coletor viu o item. A ordenação padrão usa a melhor data disponível, sem apresentar a data de coleta como se fosse a data do ato.

Contrato e rastreabilidade

Os modelos preservam identificador, tipo, título, atributos, fonte e instante de coleta. A Data API também expõe effective_date e date_basis para deixar explícito de onde veio a ordenação cronológica.

Código sob Apache-2.0. Dados e documentos permanecem sujeitos às condições de suas fontes originais.

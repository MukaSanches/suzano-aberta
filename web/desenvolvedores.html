Use o mesmo acervo por Data API, API HTTP consultiva, Python, CLI ou snapshot SQLite. Cada camada tem uma finalidade clara e evita obrigar o consumidor a raspar páginas.

Semântica de datas

record é a data publicada pela fonte; year indica que só o ano foi encontrado; observed é a data em que o coletor viu o item. A ordenação cronológica usa a melhor evidência disponível e deixa a base da data explícita.

Python

from suzano_aberta import SuzanoClient, SuzanoIndex

with SuzanoIndex("suzano-aberta.sqlite3") as index:
    pagina = index.search("mobilidade", year=2026, limit=25)
    for item in pagina.items:
        print(item.id, item.title, item.source.url)

Snapshot completo

Para análise em massa, prefira o SQLite compactado publicado como release rolling, acompanhado de checksum SHA-256. Isso evita paginar toda a API só para reconstruir o acervo inteiro.

Contrato e rastreabilidade

Os modelos preservam identificador, tipo, título, atributos, fonte e instante de coleta. A Data API expõe também effective_date e date_basis, e a API HTTP mantém o contrato v1 documentado separadamente da versão do pacote e da versão do dataset.

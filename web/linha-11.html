Linha 11–Coral: Suzano e trecho leste

Acompanhe o estado operacional publicado por fontes oficiais para o eixo Calmon Viana–Suzano–Jundiapeba–Estudantes. O Suzano Aberta não estima nem inventa situação de linha: sem confirmação oficial válida, o painel informa indisponibilidade.

Consultando fontes oficiais…

Como funciona: o backend mantém cache e tenta fontes oficiais em sequência. Dados antigos são marcados como desatualizados; se nenhuma fonte puder confirmar a Linha 11, o painel não cria um status substituto.

A API Trilhos da ARTESP exige chave e, desde 3 de setembro de 2026, declara escopo apenas para linhas sob regulação direta da agência. Para a Linha 11, o módulo também verifica os canais oficiais da CPTM.

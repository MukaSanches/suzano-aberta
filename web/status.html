A Data API é publicada junto do portal. Quando uma API consultiva dinâmica está configurada, o site tenta usá-la primeiro para filtros e paginação; caso ela esteja indisponível, a pesquisa recorre ao índice local publicado.

Como a publicação evita regressões

BaixarO workflow obtém o snapshot rolling publicado.
ConferirChecksum e PRAGMA quick_check verificam o arquivo antes do uso.
ConstruirBusca, detalhes, relações, notícias, briefing Autopilot e Data API são derivados do snapshot aprovado.
ValidarHTML, links locais, diversidade do digest, conjuntos obrigatórios e integridade mínima passam por verificações automáticas.
PublicarO GitHub Pages só recebe o artefato depois das etapas anteriores.

Cadência automática

Notícias e portal são recompostos a cada 30 minutos; a atualização incremental do acervo roda a cada 4 horas; a reconstrução completa é diária; verificações externas de fontes rodam a cada 6 horas. Falhas recorrentes geram incidentes técnicos no próprio GitHub e o último snapshot válido permanece publicado.

As execuções públicas podem ser auditadas em GitHub Actions.

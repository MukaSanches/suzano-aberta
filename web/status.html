A Data API é publicada junto do portal e fornece catálogo, estatísticas, coleções completas e arquivos separados por data. Quando uma API consultiva dinâmica está configurada, o portal a utiliza para filtros; caso contrário, a busca usa o mesmo índice público validado.

Princípio de falha segura

Uma nova coleta que falha não substitui um snapshot válido. A publicação verifica integridade do SQLite, índice textual, presença de documentos e coleção legislativa antes de promover uma versão nova.

# Código de conduta

Suzano Aberta é um projeto cívico e técnico. Discussões devem permanecer respeitosas, verificáveis e centradas no trabalho.

São esperados:

- críticas ao código, não às pessoas;
- referências a fontes quando uma afirmação factual for relevante;
- abertura para revisão e correção;
- linguagem profissional em issues, pull requests e documentação.

Não são aceitos assédio, intimidação, discriminação, divulgação de dados pessoais, ameaças ou uso do projeto para atacar pessoas ou grupos.

Discussões político-partidárias que não sejam necessárias para corrigir ou documentar um dado público estão fora do escopo do repositório.

Problemas de conduta podem ser comunicados ao mantenedor por um canal privado disponível no perfil do repositório.
